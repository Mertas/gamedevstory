# GameDevStory — клон Game Dev Story (Kairosoft)

Набор проектных документов + реализация ядра для клона **Game Dev Story** (2010, Kairosoft).

## Карта документов

```
README.md                  — этот файл
plan/
  00_Обзор_проекта.md       — цели, столпы дизайна, скоуп, карта доков, источники
  01_Игровой_цикл.md        — структура времени, календарь, основной цикл, конец игры
  02_Персонал.md            — профессии, статы, найм, зарплаты, прокачка, обучение, предметы
  03_Разработка_игры.md     — пайплайн разработки, режимы, события, баги, сиквелы
  04_Жанры_типы_комбинации.md — 20 жанров, 79 типов, вердикты S–F, списки S-комбо
  05_Рейтинги_продажи_маркетинг.md — рецензии, награды, модель продаж, фанаты, реклама
  06_Железо_и_платформы.md  — 24 консоли, лицензии, базы, своя консоль
  07_Контракты_события_исследования_офисы.md — 16 контрактов, события, PR, технологии
  08_Экономика_и_баланс.md  — денежные потоки, фазы партии, калибровка, метрики
  09_Формулы_и_данные.md    — ВСЕ формулы для реализации ([О]=оригинал, [Н]=наше)
  10_Технический_план.md    — стек, архитектура, модель времени, этапы M1–M7
  11_Контент_наполнение.md  — свои названия (консоли, персонажи, журналы) и локализация
research/                    — сырые выжимки источников (для сверки)
  01_english_wiki_mechanics.md — механика по англ. вики (45 сотрудников, 79 типов,
                                  матрица совместимости 79×20, 24 консоли, 58 реплик)
  02_formulas_and_numbers.md   — цифры/формулы по гидам (StrategyWiki, GameFAQs, IGN, дамп)
  03_japanese_sources.md       — японские вики (контракты, обучение, скрытые механики)
data/
  gamedev.db                 — контентная база игры (SQLite, node:sqlite)
src/core/                    — ядро игры (чистый TS, без UI)
  data/db.ts                 — единственный доступ к SQLite (типизированные геттеры)
  engine.ts                  — создание игры, недельный тик, действия
  systems/                   — staff / dev / market
  sim/policy.ts              — скриптованный игрок для баланс-тестов
  config.ts, formulas.ts, rng.ts, types.ts
test/                        — юнит-тесты формул + баланс-прогоны (vitest)
tools/build-db.ts            — сборка gamedev.db из research/*.md (pnpm db:build)
scripts/playthrough.ts       — CLI-прогон партии (pnpm play [seed] [days])
```

## Команды

```bash
pnpm db:build     # пересобрать data/gamedev.db из research/*.md
pnpm test         # юнит-тесты формул + баланс (5 сидов × 24 месяца; сейчас 50/50)
pnpm play 1 730   # CLI-прогон партии сидом 1 на 730 ДНЕЙ (без UI; аргумент — дни, не недели)
pnpm avatars      # аватарки сотрудников (48 шт из LLMKing/data/icons → public/avatars)
pnpm server       # игровой сервер: :3001 (WebSocket /ws + /api/save + статика dist)
pnpm build        # tsc + сборка клиента в dist/
pnpm dev          # dev-режим клиента (vite :5173; игра всё равно на :3001)
```

Игра: `pnpm build && pnpm server` → http://localhost:3001

## Ключевые решения

- Механика — оригинала 2010; контент — свои названия (см. 11).
- Точных формул продаж/рецензий в оригинале нет — модель клона в 09, помечена `[Н]`.
- **Вся игра — на сервере** (Node): движок, БД (node:sqlite), чат, GigaChat (секреты не
  покидают сервер). Клиент — чистый UI: WebSocket `/ws` (снапшоты + действия) + HTTP `/api/save`.
- Стек: TS + vitest (ядро), React + Vite (UI), Express + ws (сервер), тик = день (1 сек на 1×), 20 лет.
