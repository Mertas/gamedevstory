# PLAN-46: Квестовые попапы с артами + занос в LLMPics (v1.44.0)

Статус: в работе, 03.10.2026.
Задача (босс): «для каждого шага квеста нужно сделать красивый большой попап со своим
оформлением, где будет большая картинка. все возможные шаги нужно занести в llmpics».

## Объём артов (33)

- Процедурные квесты (11): pirates, interview, fanletter, sponsor, conference, leak,
  museum, rivals, birthday, charity, hardware — по одному шагу-сцене.
- Авторские арки (6, шагов 22): offer×3, burnout×4, dream×4, rivalry×3, mentorship×3,
  generations×5 — каждая ветка (завязка + эпилоги) получает свою сцену.
- Один арт на шаг. Ключ: `<template>` для квестов, `<arcId>-s<step>` для арок.
- Файлы: `public/quests/<key>.png` (Vite копирует public → dist, URL `/quests/<key>.png`).

## Дизайн попапа (GDS)

- Расширение MessageBox (не новый канал): `art?: { src, emoji?, accent? }` включает большой
  режим — окно ~660px: шапка win95 (title), баннер 16:9 full-bleed (pixelated), акцентная
  полоса, текст, кнопки. Автопилот-таргеты `mb-*` и evKey-механика — как есть.
- Фолбэк: картинка ещё не сгенерирована / ошибка загрузки → плитка 16:9 с крупной эмодзи
  на акцентном градиенте. Пока артов нет — все квесты показываются в фолбэке (норма).
- Карта `src/ui/questArt.ts`: emoji + accent на 17 базовых записей (11 квестов + 6 арок).

## LLMPics: проект `gds-quests` + широкий кадр

- Проект: `data/projects.json` + `data/projects/gds-quests/{subjects.json, meta.json}` —
  33 цели (description — сцена по-английски, style — пиксель-арт каркас + персональный
  акцент). Экспорт: `E:/MY/GameDevStory/public/quests`, `{subject}.png`, копия as-is.
- Режим «Широкий кадр» (`wide`): латент 1024×576 в comfy.ts (нативно, без рецепта-деления),
  превью 64×36; поле `wide` в GenOptions/ProjectSettings/VariantMeta; чекбокс в форме и
  пресете; подписи «1024×576». Квадратный путь не трогаем.

## Решения по развилкам (формы истекли — взяты рекомендованные варианты)

- Объём: все 33 арта (квесты + арки). Переключаемо — скажи, если только квесты (11).
- Формат: 16:9 баннер + доработка LLMPics. Альтернатива — квадрат 1024 с кропом в попапе.
- Стиль: PixelArtXL, у каждой сцены своя атмосфера/палитра.
- Оформление: единый большой каркас + акцентный цвет от квеста.

## Метрики готовности

- `pnpm typecheck` + тесты (вкл. ui-contract/автопилот) зелёные; смоук живым DOM: квест-попап
  c баннером (или фолбэком) открывается, кнопки решают квест как раньше.
- LLMPics: wide-генерация 1024×576 проверена на ComfyUI (или откат к квадрату с кропом).
- Версия v1.44.0, прод-деплой, скилл-заметки обновлены.
