# PLAN-22: открытые комбо, уровни и звания игрока

Запрос пользователя (дословно):
1. «Не показывай уровень комбо до тех пор, пока игру не начали делать.»
2. «У каждого пользователя вне зависимости от сейва выводиться в форме новой игры должны только открытые им уровни комб.»
3. «Количество открытых комб — это уровень пользователя, выводи его в окне выбора сейва как-нибудь прикольно.»
4. «Сделай пороги уровней и называй пользователя крутым программистом, гейм-девелопером в зависимости от порога уровня. Напиши небольшой текст почему тот или иной программист или гейм-девелопер крутой.»

## Как устроено сейчас

- Комбо = пара «жанр × тип»: **20 жанров × 79 типов = 1580 пар**. Оценка (S/A/B/C) — статичная таблица из контент-БД (`comboGradeFrom`, `src/shared/rules.ts`).
- Доступность жанра/типа считается **от текущего сейва**: `isUnlocked(game, genre.unlockJob, genre.unlockLevel)` — должности/уровни сотрудников + пройденные тренинги (`src/core/systems/dev.ts:54`, `Wizard.tsx:82,86`).
- Бейджи комбо видны в визарде до старта: подсказка «Комбо с "жанр": S — отлично, A — хорошо» (`Wizard.tsx:267`), оценки в списке типов (`:272`), в итоговой таблице (`:381`), в подвале (`:439`). После старта — `Dev.tsx:244` («комбо C» в шапке проекта).
- В сейве есть `history: GameRecord[]` (у каждой записи `genreId`/`typeId`) и активный проект — по ним можно засеять набор.

## Предлагаемая механика

**Хранение (виртуальная валюта прогресса, не сейв):** `users.db`, таблица
`user_combos(user_id INTEGER, combo TEXT, first_at INTEGER, source TEXT, PRIMARY KEY(user_id, combo))`,
где `combo = "<genreId>|<typeId>"`, `source ∈ start|release|seed`. Набор только растёт.

**Пополнение набора:** в момент, когда игрок ЗАПУСКАЕТ проект с парой (вопрос 1), сервер пишет пару в
`user_combos`. Синхронизация — на `start_project` и на автосейве (на случай старых сейвов).

**Визард «Код»:** список пар = набор аккаунта ∪ доступное по правилам текущего сейва (вопрос 2).
Сначала набор пуст — базовая линейка берётся из правил сейва, дальше всё, что игрок когда-либо открыл,
доступно в любой новой игре.

**Оценка комбо (S/A/B/C) скрыта во всём визарде** до старта проекта (пункт 1): убираем из списка типов,
из подсказки, из итоговой таблицы и подвала. В шапке разработки (`Dev.tsx:244`) остаётся как было.

## UI

- **StartScreen (окно выбора сейва):** карточка «Профиль разработчика» в стиле Win95 — большая иконка
  звания, название, строка «Открыто комбо: N» с прогресс-баром до следующего звания (сегменты, как в
  установщике), и текст «почему крутой». Обновляется после каждого открытия.
- **Wizard:** бейджи комбо скрыты (см. выше); вместо оценки — ничего, пока проект не начат.
- **История:** новые звания можно логом («🎖️ Новое звание: Крутой программист — 11 комбо!»).

## API

`GET /api/profile` → `{ ok, level: N, title, icon, next: {title, need}, combos: [...], why }`.
Данные берутся из `user_combos` + текущего сейва (union). Авторизация — по cookie сессии.
