## 1. Рецензии журналов

- После релиза игру рецензируют **4 журналиста, каждый даёт до 10 очков** → максимум 40.
- Оценка зависит от очков игры (Fun/Creativity/Graphics/Sound), найденных багов и **аудитории журналиста** (у разных журналистов разные веса — «игра привлекает разные аудитории»).
- Найденные баги снижают оценку.
- Случайность: при одинаковых параметрах оценки могут различаться (подтверждено сообществом).

## 2. Награды (ежегодно, декабрь)

Вход: игра в Зале Славы (32+). После первого входа компания всегда конкурирует.

| Награда | Приз | Условие |
|---|---|---|
| Лучший дизайн | **$100K** | высокие Graphics |
| Лучшая музыка | **$100K** | высокий Sound |
| Второе место | **$500K** | (IGN: $300K — ошибка; дамп игры: 500K) |
| Худшая игра | **−$300K** | релиз с 50–60 багами (или очень плохая комбо) |
| Гран-при (GOTY) | **$1,000K** | ≥36/40 (шанс), 160+ во всех категориях (надёжно) |

**Анлоки по Гран-при** (яп. источники): 1-я победа → спец-сотрудник (Медведь); 2-я → консоль «Юпитер 512» (нужно ещё 16M продаж одной игры); 3-я → спец-сотрудник (Шимпанзе); 5-я → консоль «GameJohn» (нужно 20M продаж) + легендарный робот-сотрудник.
**Совет сообщества**: качать все 4 параметра выше 150 (лучше 200) — тогда Гран-при «почти гарантирован»; сиквелы в поздние годы делают Гран-при легче; 3–4 игры в Зале Славы за год размывают конкуренцию.

## 3. Продажи: модель

**Точная формула оригинала не опубликована нигде** (подтверждено всеми источниками) — ниже модель клона `[наше]`, калибруется в 08/09.

### 3.1. Множители (ежемесячная база)

```
Продажи_за_неделю = База_платформы × Доля_рынка_игры × Множители

База_платформы = установленная база консоли (тыс.)
Доля_рынка_игры = f(рецензии, комбо, популярность жанра, цена, фанаты, хайп/известность)
```

| Фактор | Множитель (наше) |
|---|---|
| Рецензия 40/40 | 1.0 + (score − 20) / 20 → 0.5..2.0 (20 = «нейтрально») |
| Комбо S/A/B/C/D/F | 1.5 / 1.3 / 1.1 / 1.0 / 0.8 / 0.5 |
| Популярность жанра A/B/C | 1.2 / 1.0 / 0.85 |
| Фанаты | 1 + log10(1 + фанаты/100) → 1.0..~1.8 |
| Хайп+известность (0–200) | 0.8 + (hype+fame)/400 |
| Реклама после релиза | +5–15% за кампанию |
| Зимний пик (M12 W1) | ×2 на эту неделю |
| Сиквел | ×1.2 (плюс стартовые очки) |
| Конкуренция (чужой хит того же жанра) | ×0.7 |
| Гран-при/награда за игру | ×1.25 (постоянно для этой игры) |

### 3.2. Кривая жизни

- Релиз → пик в первые 1–2 недели → **еженедельный спад** → снятие с продаж через ~4–8 месяцев.
- **M12 W1 — пик зимних продаж ×2**: релизы в ноябре–декабре выгодны.
- Выход в топ-10 чарта — дополнительный буст.
- Консольный множитель «доход за копию»: новее/дороже консоль → выше доход (в оригинале — «more money per game»). `[наше]`: доход_за_копию = 0.5 × множитель_платформы (×1..×30 из таблицы консолей) — калибровка.

### 3.3. Цена игры

**В оригинале ползунка цены НЕТ.** `[наше]` для MVP: цены тоже нет — копия продаётся по фиксированной цене платформы. Опция «установить цену» — кандидат в M7 (расширение), с моделью эластичности.

## 4. Фанаты

- Фанаты делятся на **возрастные группы** (5–12 / 13–18 / 19–24 / 25–40 / 41+) и пол.
- Фанаты **стареют** — нужно постоянно привлекать молодых.
- Фанаты растут от: рекламы (с убыванием — у каждой рекламы свой потолок), писем фанатов (положительные рецензии), наград, стендов Gamedex, релизов.
- Падают от: плохих игр (отрицательные письма), простоя без релизов, повторения жанр+тип дважды подряд, провалов контрактов.
- Влияние: множитель продаж (выше) + порог для спец-событий (7,000+ → Гран-при доступнее).
