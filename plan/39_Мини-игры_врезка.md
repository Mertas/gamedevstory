## Механика

- В разработке (`devTick`) при `progress >= 0.5` (флаг `mg50` не выставлен, событий нет) —
  событие `pendingEvent = { type: 'minigame', gameId: '' }`. Пока событие висит, игровое
  время стоит штатной паузой тикера (как бусты/дизэстеры).
- Сервер добирает `gameId` из **ротации мешком без повторов**: аккаунт, `user_flags['mg_bag']`
  (все четыре по разу в случайном порядке, потом новый круг; на стыке кругов подряд не повторяется).
- Формат: поверх стола — SVG-монитор «SONNY», внутри его кинескопа — игра (iframe `/lab/`, v0.59).
  Кнопки пропуска **нет**; партию можно **закрыть** («ЗАКРЫТЬ ПАРТИЮ» → «ТОЧНО? ШТРАФ -2 PR») — это
  максимальный штраф (цена в параметре `pen`), результат не засчитывается. Экран итога и
  «ПРОДОЛЖИТЬ» — тоже внутри врезки.
- Результат игры (0–100%) уезжает из iframe в GDS; эффект (маленькие числа, подстроим):
  **≥70% → +3 PR · 40–69% → без изменений · <40% → −2 PR** (пол — 0). Строка в журнал игры.
- Автопилот (если включён): мини-игру не играет — закрывает нейтрально (0), в лог
  «мини-игра пропущена (автопилот)».
- Возможные следующие врезки (33%, 66%) — задел, сейчас только 50% (как просил).

## Архитектура

- **Песочница (`E:/MY/gds-minigames`)**: embed-режим одной страницы —
  `?embed=1&g=g104&p=<base64url>&snd=0|1&pen=2` прячет меню/панели/историю, открывает игру сразу,
  параметры отдаёт через `window.__mgParamsInject`, результат — `window.mgDone(pct, rank)` →
  `postMessage` родителю. Звук: `snd=0` глушит; `pen` — цена закрытия для кнопок врезки (v0.59).
  Внутри врезки `mgxBuildCrt` собирает CRT-полосу: HUD-строка из `.hud` игры, кинескоп `.term-wrap`,
  панель «ЗАКРЫТЬ ПАРТИЮ»; габарит врезки 686×539 (670×523 + padding 8) — под него вырезан монитор.
- **GDS**: модалка-монитор `SonnyMonitor` (`src/ui/SonnyMonitor.tsx`, SVG 750×640) с iframe на `/lab/`
  (относительный путь — отдают: vite-плагин labStatic в dev; `pnpm server` из `E:/MY/gds-minigames`
  (env `GDS_LAB_DIR`, v1.46.1 — без него SPA-фолбэк показывал в iframe саму игру); в проде — nginx).
  Мосты: iframe → `{source:'gds-mg', type:'done', pct, rank}` |
  `{type:'close'}` | `{type:'continue'}`; GDS → `{source:'gds', type:'result', note}` и action
  `resolve_minigame {pct}` / `{closed: true}`.
- Клиент и сервер используют одну общую таблицу ротации/настроек (`src/shared/minigames.ts`).
