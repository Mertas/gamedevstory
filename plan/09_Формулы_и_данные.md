# 09. Формулы и данные — сводка для реализации

> **Статус цифр:** [О] = подтверждено оригиналами/сообществом (источник в research/); [Н] = наше проектное решение (GAP, формула не опубликована). Все формулы [Н] калибруются в M6 скриптовыми прохождениями (08 §5).
> **Масштаб денег:** оригинал оперирует в 万 (×10,000 ¥); англ. вики — в $K. Конверсия: **1 万 = 0.1 $K** (напр., лицензия IES 8,000万 = $800K ✓, своя консоль 40,000万 = $4,000K ✓). В клоне — абстрактные единицы «K» (тысячи).

## 1. Стартовые условия [О]

Деньги **$500K**; очки исследований **10**; сотрудники: Кодер Lv1 ($20K/год) + Сценарист Lv1 ($20K/год); офис 1 (4 места); доступны: PC + Microx SX, 6 методов найма первого уровня, 5 реклам, 7 контрактов, жанры/типы «с старта».

## 2. Разработка: очки и время [Н, калибруется]

### 2.1. Стоимость проекта
```
стоимость_K = (жанр_база × жанр_множитель_уровня + тип_база × тип_множитель_уровня) × множитель_платформы × множитель_режима
жанр_база:  200..2,500 (таблица 04 §3, ед. 万 → ×0.1 = K)
тип_база:   150..1,450 (research/03 §4)
жанр_множитель_уровня: 1 + 0.5×Lv (Lv5 → ×3.5; верхняя граница в оригинале ~×10 — берём ×3.5, калибровка)
множитель_платформы: таблица 06 §2 (×1..×30)
множитель_режима: Обычный 1.0, Скорость 1.2, Качество 1.3, Исследования 1.5, Бюджет+ 2.0 [О]
```
Примеры-якоря [О]: Пазл+Реверси на PC ≈ $55K; RPG+Фэнтези ≈ 2,215万 = $221.5K.

### 2.2. Недельный прогресс
```
очки_за_неделю = Σ по назначенным ролям ( стат × 0.7 × рольМножитель × усталость × режимМножитель )
рольМножитель:  Программирование → Fun 1.0, Graphics 0.3
                Сценарий → Creativity 1.0, Fun 0.2
                Графика → Graphics 1.0
                Звук → Sound 1.0
усталость: POWER ≥5 → 1.0; 2–4 → 0.7; <2 → 0.4 (при 0 сотрудник уходит домой)
режимМножитель: Обычный 1.0; Скорость 1.15 (но баги ×1.5); Качество 0.85 (баги ×0.7); Исследования 0.9 (PR ×1.5); Бюджет+ 1.25 (баги ×0.85)
```
Якоря: 2 стартовых сотрудника (статы ~20) → ~28 очков/нед → первая игра ~2 недели [О: ~1 месяц]; макс-команда 8×300 → ~1,700/нед → поздняя игра 39,000K ~23 недели.

### 2.3. Оси направления [Н]
10 очков направления на игру (распределяются по 8 осям). Вектор весов оси → атрибуты:

| Ось | Fun | Creativity | Graphics | Sound |
|---|---|---|---|---|
| Милота | 0.4 | 0 | 0.6 | 0 |
| Реализм | 0 | 0 | 0.7 | 0.3 |
| Доступность | 0.8 | 0.2 | 0 | 0 |
| Нишевость | 0 | 1.0 | 0 | 0 |
| Простота | 1.0 | 0 | 0 | 0 |
| Инновационность | 0.2 | 0.8 | 0 | 0 |
| Игровой мир | 0.5 | 0.5 | 0 | 0 |
| Полировка | 0.25 | 0.25 | 0.25 | 0.25 |

Фактически: `атрибут += очки_недели × (Σ_осей очки_оси/10 × вес_оси)`.
Запас очков направления: старт 10 [О «some points»], **+2 за жанр на Lv2 и Lv5** [О]. Совпадение направления с жанром/типом ускоряет их левел-ап [О, механика «match»].

### 2.4. События разработки [О + Н частоты]
- Буст-предложение: ~60% шанс ×1 за проект (25–75% готовности). Успех: +25–50 очков (статы сотрудника; шанс = 0.5 + Σстаты/400, кап 0.8; PR поднимает: +1% за 5 PR). Провал: +20–30 багов, −ожидания. [О: +25–32 / +30–50; берём диапазон, калибровка]
- Блэкаут: 4%/нед; −30% всех очков [О: «половина» (IGN) / 20–50 (вики) → берём 30%, калибровка].
- Поломка: 3%/нед; −10–20 очков.
- Штраф «повтор»: тот же сотрудник та же роль 2-й раз подряд → ×0.6 [О: механика «prev»].
- Медиа-события после релиза: 12%/нед первые 8 недель: статья (+8% продаж), TV (+15%), «найден баг» (−10%, если баги на релизе >0).

## 3. Баги [О + Н]

```
баги_проекта = (стоимость_K / 200) × режимМножительБагов + баги_событий + бонус_плохой_комбо(F: +10)
скорость_отладки = Σ Program × 0.2 багов/нед
```
- Каждый вычищенный баг → **1–3 PR** [О]. Баги на релизе: рецензенты находят (шанс = min(1, баги/15)) → −1 очко рецензии за найденный баг [Н].
- **50–60 багов на релизе → антипремия −$300K** [О].
- «Багочистка» (технология): скорость отладки ×1.5 [О: ускоряет].
- Bug Spray (предмет): убирает 30 багов за PR [О].

## 4. Рецензии [О + Н]

```
рецензия_журналиста = clamp( round(3 + W_j / 40 + noise(−1..1) − найденные_баги), 3, 10 )
W_j = Fun×wF + Creativity×wC + Graphics×wG + Sound×wS
веса журналистов:  J1: 1.0/0.6/0.7/0.5   J2: 0.8/1.0/0.8/0.6
                    J3: 1.2/0.5/0.9/0.9   J4: 0.6/0.6/1.2/1.2
```
Якоря: все атрибуты ~100 → ~6/журналист (24/40); ~160 → 7–8 (30/40, HoF); ~240+ → 9–10 (36–40, шанс Гран-при) [О: 160 во всех = надёжный Гран-при, 40 не гарантирует].
Сообщения-баллы — таблица 05 §1 (58 строк, для локализации).

## 5. Продажи [Н, модель]

```
продажи_за_неделю = база_консоли × 0.02 × Доля_рынка × сезон × кривая
Доля_рынка = рецензияМножитель(0.5..2.0: 1 + (score−20)/20)
          × комбоМножитель(1.5/1.3/1.1/1.0/0.8/0.5)
          × популярностьЖанра(1.2/1.0/0.85)
          × фанаты(1 + log10(1 + фанаты/2000), кап 3.0 — аудит 05.09: было /100, кап на ~10K)
          × хайп_известность(0.8 + (fame+hype)/200, кап 1.8)
          × сиквел 1.2 × награда 1.25 × конкуренция 0.7
          × реклама_после_релиза (1.05..1.15 за кампанию)
кривая: неделя 1: 15% всего объёма; w2: 12%; далее ×0.82/нед; игра в продаже 24 недели
сезон: M12 W1 ×2 [О]
доход = продажи × цена_копии_платформы (0.5K × множитель_платформы) [Н]
своя_консоль: база_консоли × 0.04 вместо 0.02 (нет конкуренции) [Н]
```
Якоря (цели калибровки): первая игра ~10–30K копий; хит (32+, A-комбо) на PlayStatus (6M) ~1M; эндгейм на ультимейт-консоли (30M+ база, всё максимально) — десятки млн; 100M — почти невозможно (ачивка-«миф»).

## 6. Популярность жанров во времени [Н]

```
популярность = база(A=1.2/B=1.0/C=0.85) + амплитуда 0.25 × sin(2π(год − фаза)/период)
период 5–8 лет, фазы разнесены; градации: >1.12 A, 0.95–1.12 B, <0.95 C
```
Первый жанр-лидер меняется каждые ~2–3 года — игроку выгодно следить за трендами [О: «популярность жанров меняется со временем»].

## 7. Фанаты и реклама [Н]

- 10 групп (5 возрастов × 2 пола). Каждая игра/письмо/реклама влияет на группы.
- Рост: реклама (ниже), релизы (+0.5% от проданных копий в «свои» группы), положительные письма (+10–50), награды (+200), Gamedex (+300–2,000).
- Спад: плохие игры (−), простой без релизов (−2%/мес), дубль жанр+тип (−), провал контракта (−100).
- **Потолки рекламы** (суммарный кап фанатов на тип кампании): журнал 2K, онлайн 3K, радио 4K, демо 6K, оркестр 8K, ТВ 15K, талисманы 12K, ТВ-спонсор 20K, гонки 30K, турнир 60K, дирижабль 90K, Луна 150K. Прирост за кампанию = (кап − накоплено) × 0.15 + 50.
- Хайп: +успешные бусты (+5..15), +реклама во время разработки (+3..20). Известность: награды, Gamedex, статьи, контракты. Обе шкалы 0–100.

## 8. Персонал [О]

- Зарплата: `база × 1.2^Σуровней`; платёж в конце марта; 1-й год бесплатно.
- Взнос при найме — по таблице пула (02 §3).
- Уровни: стоимость PR по таблице 02 §5; приросты статов — research/03 §5.2.
- Обучение: таблица 02 §6; убывание эффекта: множитель = max(0.15, 1 − 0.15×использований) на метод-сотрудника; супер-эффект 5% ×3; Пинбол: 25% × (+6 ко всем), без убывания.
- POWER: макс 8–30 (по сотруднику); −2/нед за работу, −3 за обучение; +3/нед в простое; 0 → домой на 1–2 нед (восстановление до макс).
- Смена профессии: Учебник ($50K/$200K/$550K по офису); требования пререквизитов Lv5 — 02 §2.

## 9. Контракты [О — таблица 07 §1]

- Выполнение: назначенные сотрудники дают прогресс по требованиям (статы против требований за неделю); все требования ≥ минимума до дедлайна → успех.
- Награда и PR — из таблицы (сроки 6–13 нед). Провал: −репутация (−100 фанатов) [О].
- Генерация предложений: 2–4 активных, обновление ежемесячно; пул по офису [Н].

## 10. Исследования и технологии [О]

- PR: разработка (≈0.5×очков_недели×0.1), отладка 1–3/баг, контракты, «болтовня» (+1–3/нед за соседство), режим Исследования ×1.5.
- Технологии: покупка у продавца (цены растут); использование: `floor(текущий_PR / 5)`, мин 30, макс 190.
- Бустеры: правило ключевой профессии 20/10/0 очков (02 §7).

## 11. Железо [О]

- Таблицы консолей и своей консоли — 06 §2–3.
- Рост базы: +100K за игру под консоль; своя: +150K [Н]; декабрьский релиз консоли: стартовая база ×1.5 [О: декабрь лучше].
- Снятие: уведомление за 3 месяца; PC и Mini Status+ не снимаются.

## 12. Награды [О]

Призы: Дизайн $100K, Музыка $100K, Второе $500K, Худшая −$300K, Гран-при $1,000K. Вход: Зал Славы (≥32). Шанс Гран-при: рецензия ≥36; надёжно: ≥160 во всех атрибутах. Анлоки Гран-при: 1/2/3/5 побед (07 §6). Участвуют игры года (январь–декабрь).

## 13. Сиквелы [О + Н]

- Условие: оригинал ≥32 и в истории последних 32 игр; жанр/тип фиксированы; 1 сиквел на игру; сиквел ≥32 → может иметь свой сиквел.
- Стартовые очки: 30% финальных атрибутов оригинала + 50 Fun [О: +50 Fun; 30% — наше].
