# PLAN-48: Главный герой (игрок) + партнёр с долей (v1.45.0)

Статус: реализовано (v1.45.0; мастер из 5 шагов — v1.45.3: характер-textarea, UI без «статов»). Тесты 469/469, миграция сейва v13.
Задача (босс): «Сделаем главного героя, это будет игрок, вечный сотрудник… генерация
персонажа: имя, аватарка, начальные статы, профессия (1 lvl), характер (10 + свой ввод →
в LLM). Его нельзя уволить. Потом выбираешь одного сотрудника, с кем открываешь компанию;
слайдер 0–20% доли — от неё зависят статы. Уволить партнёра можно только двумя вариантами».

## Зафиксированные параметры (ответы босса, 04.10.2026)

1. **Статы ГГ:** бюджет **40 очков**, шаг 1, один стат **не выше 30**, минимум 0.
2. **Доля партнёра → статы:** **+1 ко всем четырём статам за каждый 1%** (плоский линейный рост).
3. **Увольнение партнёра:** ровно **два варианта** — выкуп **D% текущей кассы разом**
   ИЛИ рента **D/4 % от дохода от игр навсегда** (при D=20% → 20% и 5%).
4. **Зарплата:** стандартная у обоих; у ГГ — тоже (20K/год, как базовые оклады пула).
5. **Чат:** реплики игрока подписываются **выбранным именем ГГ**, не «Вы» (и его аватаркой).
6. **Профессия ГГ:** только стартовые четыре — Кодер / Сценарист / Дизайнер / Звукорежиссёр.
7. **Характер:** 10 пресетов (кнопка «Следующий ▸» по кругу) + поле «свой вариант»;
   текст характера уходит в LLM-чат вместо persona из БД.

## Механика

- **ГГ** — `staff[0]` с флагом `hero: true`, `id: 'hero'`, `avatarId: 'player-NN'` (аватарки
  игрока из LLMPics `gds-player-avatars`, 20 шт.), `persona` — выбранный характер.
  Не увольняется (защита в движке + UI без кнопки). Участвует в чате наравне с командой.
- **Партнёр** — `staff[1]` с полем `partnerPct: 0..20`. Начисление: +D к каждому из четырёх
  статов (и caps пересчитываются от новых статов). Найм бесплатный (со-основатель),
  оклад из данных пула (20–28K).
- **Выкуп**: `cost = round(money * D / 100)`, списывается сразу, партнёр уходит.
- **Рента**: `state.partnerRentPct = D / 4` — навсегда; с этого момента каждый дневной
  доход от продаж игр урезается на этот процент (dailySales, тихо).
- Старые сейвы: поля необязательны, миграция v13 — no-op (`partnerRentPct ?? 0`).
  ГГ появляется только в новых партиях; легаси-старт (двое из пула) сохранён как фолбэк.

## Старт новой игры (UI, NewGameForm)

Две секции в одном окне:
- **Шаг 1 «Главный герой»**: имя (инпут + 🎲 локальный список), аватарка (сетка 20 плиток
  `player-01..20`), статы (40 очков, −/+ по шагу 1, кап 30, счётчик «осталось»),
  профессия (4 кнопки), характер (пресет + «свой»).
- **Шаг 2 «Партнёр»**: карточки пула (одиночный выбор), слайдер доли 0–20% с живым
  превью (статы +D, условия расставания с числами).
- Футер: состав, суммарная зарплата, «▶ Начать игру» (валидно: имя, сумма статов ровно 40,
  выбран партнёр).
