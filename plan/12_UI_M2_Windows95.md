# 12. M2 — UI «Windows 95 Game Studio»

> Решения по ответам пользователя: сервер — да (GigaChat нельзя из браузера); свой `.env`;
> модель/фолбэк — как в LLMKing (GigaChat-2-Max → 2-Pro → 2 → DeepSeek); генерация чата — пофазно;
> при недоступности LLM чат не генерирует шаблоны — только системная заметка; время идёт само
> (ускорение/замедление); делаем ВСЕ окна сразу; строгая имитация Win95; аватарки — случайные
> из сгенерированных в LLMKing (позже админка + генерация); чат на русском; звуков нет.

## 1. Архитектура

```
браузер (React + Vite)
  ├─ /api/chat/generate  →  локальный Node-сервер (Express, :3001)
  │                        ├─ giga.ts — OAuth GigaChat (токен 30 мин, rejectUnauthorized:false),
  │                        │            фолбэк-цепочка, ретраи, таймауты (порт из LLMKing/src/server/models.ts)
  │                        ├─ chatgen.ts — промпты фаз + парсинг JSON-ответа
  │                        └─ config.ts — .env (свой, значения скопированы из LLMKing/.env)
  └─ статика (dev: vite :5173 + proxy /api; prod: сервер раздаёт dist/)
```

- **Секреты только на сервере.** Браузер ничего не знает о ключах.
- Движок (`src/core`) не трогаем — M1-тесты (33) должны остаться зелёными. UI-слой поверх.

## 4. Игровое время (тикер)

- `ticker.ts`: `setInterval` с периодом = 1500 мс / скорость (1 неделя игры за тик).
- Скорости: пауза, ½×, 1×, 2×, 4×, 8× — контрол в трее. 1×: год ≈ 78 с, партия ≈ 22 мин.
- При `pendingEvent` (буст) тикер ставится на паузу, показывается MessageBox; после выбора — продолжение.
- Каждый тик: `tick(state)` + доставка сообщений чата, чья неделя наступила + автосейв (localStorage, раз в неделю).

## 5. Чат (генерация пофазно, GigaChat)

**Данные**: `state.chat: ChatMsg[]` (week, author, avatar, text, system?) + `state.chatQueue: PendingMsg[]`
(сгенерированные реплики с неделей появления). Всё в сейве — детерминизм.

**Фазы генерации** (каждая — 1 вызов LLM, ответ JSON `{"messages":[{"author","text"},...]}`):

| Фаза | Триггер | Контекст в промпте | Реплик |
|---|---|---|---|
| kickoff | старт проекта | состав команды (имена/профессии/статы/характеры), жанр×тип, консоль, режим, направление, роли | 4–7 |
| alpha | прогресс ≥40% | графика/дизайнеры, первые впечатления | 2–4 |
| beta | прогресс ≥80% | звук, «почти готово» | 2–4 |
| debug | разработка 100% | баги, отладка, дедлайн | 2–4 |
| release | релиз | рецензии (баллы, Зал Славы), продажи | 3–6 |
| boost | буст-событие (успех/провал) | факт события | 1–2 |

**Темп**: пачка фазы распределяется равномерно по неделям фазы (длительность фазы из
`game.totalCost / weeklyPoints`): сообщение появляется каждые `длительность/кол-во` недель.
«Печатает…» — за 1 тик до появления.

**Промпт**: системный: «ты — корпоративный чат игровой студии; реплики 1–2 предложения, русский,
живой корпоративный юмор; характеры по профессиям (кодер — мемы/самокритика, сценарист — пафос,
дизайнер — эстет, звукорежиссёр — перфекционист, продюсер — менеджмент-речь); верни ТОЛЬКО JSON
{"messages":[...]}». Ответ парсим `extractJsonObject` (порт из LLMKing), валидируем: автор ∈ состав,
текст 5–400 символов, ≤ 8 сообщений. При провале — 1 ретрай (следующая модель фолбэк-цепочки),
затем системная заметка «связь с сервером потеряна» (по решению: без шаблонных фраз).

**Сервер** (`src/server/`): `server.ts` (Express, /api/health, /api/chat/generate, статика dist),
`giga.ts` (OAuth: Basic auth client_id:client_secret, RqUID, scope=GIGACHAT_API_PERS; запросы с
`rejectUnauthorized:false`; фолбэк-цепочка; timeout 120 с), `chatgen.ts`, `config.ts` (.env:
GIGACHAT_CLIENT_ID/SECRET, DEEPSEEK_API_KEY/BASE_URL/MODEL, PORT=3001).

## 6. Аватарки

- `tools/make-avatars.ts` (sharp): берёт **случайные 48** файлов из `E:/MY/LLMKing/data/icons/`,
  ресайз 48×48 → `public/avatars/avatar-01..48.png`.
- При `newGame`: каждому сотруднику детерминированно (по rng) назначается аватар из списка;
  хранится в `Staff.avatar`. Спец-сотрудники — тоже случайные (позже админка/генерация).

## 7. Сейвы

- Автосейв каждую неделю в localStorage (ключ `gds-save`); «Пуск → Сохранить» (экспорт JSON-файла)
  и «Загрузить» (импорт). Схема — `state` + `chat` + `chatQueue` + `rngState` (движок уже сериализуем).
