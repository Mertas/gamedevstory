# PLAN-42: Пререквизиты смены профессии — только руководство, только по требованиям

Статус: реализовано (v1.32.0). Запрос игрока 26.09.2026: «я из кодера с руководством сделал хакера.
так быть не должно. давай продумаем и сделаем логичные пререквизиты для смены профессии +
профессию должно быть можно сменить только с руководством, и только на доступную по пререквизитам».

## Правила (утверждено игроком)

1. **Смена профессии — ТОЛЬКО по руководству** (продавец, первый месяц мая, с года 2; запас
   покупается заранее). Свободной смены («по уровням на высшие») больше НЕТ — действие
   `change_career` удалено полностью (engine/actions/wire/store/UI).
2. **Руководство требования НЕ снимает**: цель должна быть доступна по пререквизитам. Иначе —
   отказ с текстом «Не хватает: …», руководство не тратится.
3. **Пререквизиты** (уровни на ТОМ ЖЕ сотруднике):

   | Профессия | Требования |
   |---|---|
   | Кодер / Сценарист / Дизайнер / Звукорежиссёр | — (база) |
   | Режиссёр | Сценарист 5 + Кодер 5 |
   | Продюсер | Сценарист 5 + Дизайнер 5 |
   | Инженер железа | Режиссёр 5 + Продюсер 5 |
   | Хакер | ВСЕ семь остальных профессий по Lv5 (высшая ступень) |

4. Бонусы первого входа (PLAN-41: статы к профилю, пороги ×1.5, ×10 за залитые) — без изменений;
   возврат в освоенную профессию — простое переключение.

## Прозрачность (окно сотрудника)

- Чипы 8 профессий стали кнопками: текущая — синяя ●, заблокированные — 🔒; клик выбирает цель.
- Для выбранной цели панель показывает:
  - требования по пунктам: «Сценарист Lv5 — у вас Lv3 ✗» (зелёный/красный);
  - **превью порогов**: «Пр 36 → 591 (+555 ×10) · Сц …» — те же формулы, что в ядре
    (`careerChangePreview` в `src/shared/train.ts`, один источник с `changeCareer`);
  - превью статов: «Сц 100 → 115» (×1.15 профиля);
  - «Профессия знакома — простое переключение, статы и пороги не изменятся» — для повторного входа.
- Кнопка «📘 Сменить на «X» (руководств: N)» — активна только при выполненных требованиях И
  запасе ≥ 1; рядом подсказка, чего не хватает / что потратится руководство.
- Старый текст «Смена профессии — в «Найм» → «Профессии»…» из окна убран.
