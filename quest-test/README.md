# QuestTest — локальный стенд теста саги «Синяя Комета»

Отдельная страница (без обвязки игры), дизайн — win95-стили игры (win95.css, штрип-акцент попапов).
Пока всё локально: не деплоится, не коммитится.

## Запуск

- `QuestTest.bat` (двойной клик) — поднимет сервер и откроет браузер.
- Вручную: `node server.mjs` → http://127.0.0.1:8899/
- Порт: **8899** (только 127.0.0.1).

## Что внутри

- **Карточка хода** — как квест-попап в игре: шапка-окно, баннер 16:9 (арт `public/quests/<art>.png`,
  если ещё нет файла — фолбэк-плитка с эмодзи), акцентная полоса, текст, варианты.
- **Жетон лица** — поверх арта, в левом верхнем углу: квадратная аватарка персонажа-хозяина сцены
  (`public/quests/face-*.png`, проект LLMPics `gds-comet-faces`, 1024×1024; пока файла нет — эмодзи).
  Поле `face` в `saga.json`; маппинг «узел → лицо» — `plan/47_Сага/07_Лица_персонажей.md`.
  Роли ({Скептик} и т.д.) — не персонажи: отдельных портретов нет, в игре их жетон = лицо сотрудника.
- **Вставки по ситуации** — условные фрагменты: флаговые включаются сами, «студийные»
  (⚡/💎/ШУМ высокий/тихий …) — галочками, чтобы примерять контекст руками.
- **Настройки чисел** — таблица калибровки: награды/штрафы по тирам (±/±±/±±±) для денег,
  доверия, ШУМа, совести, бизнеса, культуры, фанатов + порог «фанатов ≥ N». Кнопка «Сохранить» →
  пишет `settings.json` (и состояние сессии — в localStorage браузера).
- **Пол ролей** — м/ж для ролей {Скептик}, {Мечтатель}, {Технарь}, {Юрист}, {Финдир}, {Старожил},
  {Герой}, {Партнёр}: тексты показываются с родовыми формами («я пошёл/пошла») по полу роли.
  Родовые пары в текстах: `{муж/жен@роль}`; в реплике `{Роль}: «…»` можно без `@роль` — берётся
  род говорящего. Сохраняется в settings.json.
- **Панель состояния** — накопленные суммы, доверие по персонажам, флаги, артефакты.
- **История / откат** — каждый шаг; клик по строке откатывает партию к этому месту,
  кнопка «↩ Шаг назад» — на шаг, «⟲ Заново» — сброс. Клик по пройденному узлу в дереве — тоже откат.
- **Дерево вариантов** — весь граф саги: текущий узел подсвечен, пройденные — активны для откатa,
  серые — ещё не пройдено / ещё не загружено.

## Данные и как добавлять главы

- `saga.json` — машиночитаемая сага: `nodes` (главы/под-сцены), `choices` (варианты с эффектами),
  `inserts` (условные вставки), `onEnter` (эффекты при входе).
- Эффекты: `{"k":"money|trust|noise|conscience|biz|culture|fans","v":±N}`, `{"k":"flag","name":…}`,
  `{"k":"artifact","name":…}`; у trust — поле `who`.
- Загружена вся сага — **Акты I–VI + эпилоги** (в III — узлы S9б/S9в и слоты S10; IV — S13–S17 + i4; V — S18–S21 + i5, под-узлы S18б/S20б; VI — S22/S23, хаб эпилогов EP и E1–E6 со слотом первой строки). Заглушек нет.
  Тексты — из `plan/47_Сага/0*.md` (истина — md). В текстах — {Герой} и {Партнёр}:
  реплики героя, вставки по профессии (`heroJob`), фрагменты «без партнёра» (галочка «Партнёр ушёл»).
- `settings.json` — числа для калибровки (правится и из UI, и руками); там же «🎭 Пол ролей» (м/ж родовых пар), «🧑 Герой: профессия» (вставки по профессии — условие `heroJob`) и «🤝 Партнёр» (флаг «без партнёра», действует с новой партии).

## Проверки

- `node check-saga.mjs` — целостность графа саги (битые ссылки, недостижимые узлы); ругается
  на родовые пары без `@роли` вне реплик и на неизвестные `@ключи` (предупреждения, не блокирует).
- `node test-e2e.mjs` — сквозной прогон интерфейса через CDP (переходы, эффекты, откаты, дерево,
  сохранение чисел; сейчас 53 проверки — включая {Героя} (реплики, вставки по профессии) и
  {Партнёра} («без партнёра»)). Нужен chrome с `--remote-debugging-port=9334` и `ws` из node_modules игры;
  сервер стенда должен быть запущен.
- `node smoke-act3.mjs` — быстрый прогон Акта III (S1→…→i3): слоты S10, родовые пары,
  вставки {Героя}/{Партнёра}/профессий (21 проверка). Те же требования, что у e2e.
- `node smoke-act4.mjs` — сквозной прогон Акта IV (S1→…→i4): вставки по флагам/профессиям,
  cond-пометки «нужен флаг», слоты рода, жетон лица (28 проверок). Те же требования, что у e2e.
- `node smoke-act5.mjs` — сквозной прогон Акта V (S1→…→S22): флаговые вставки, cond-выборы
  копии, onEnter-флаг «Анна пришла» (29 проверок). Те же требования, что у e2e.
- `node smoke-act6.mjs` — сквозной прогон финала (S1→…→E4): пути S22, cond B/C/F, титулы S23,
  хаб EP, слот эпилога «Тишина» (20 проверок). Те же требования, что у e2e.
- `preview.png` — скриншот для быстрого взгляда.

## Файлы

- `saga.json` — контент саги. `settings.json` — числа.
- `server.mjs` — статика + API. `QuestTest.bat` — лаунчер.
